# Консольні програми на мові С — демонстрації

Демонстраційні програми до заняття 7 курсу «Системне програмування»
(ВСП «Фаховий коледж інформаційних систем і технологій КНЕУ ім. Вадима Гетьмана»).

Тема заняття — **що робить бібліотека C між вашим кодом і системою**: форматування, перетворення `\n`, буферизація, два потоки виводу — і де закінчується мова C та починаються функції Windows.

До репозиторію додається **путівник** (PDF, видається окремо) — покроковий маршрут по всіх демонстраціях у тому порядку, як на занятті. Номери станцій путівника вказано в таблиці сценаріїв нижче.

## Як відкрити у Visual Studio

**Що має бути встановлено.** Visual Studio (Community достатньо) з компонентом **«Розробка класичних застосунків на C++»** (Desktop development with C++). Якщо його немає — запустіть Visual Studio Installer, натисніть *Modify* і позначте цей компонент.

**Крок 1. Відкрити рішення.** Двічі клацнути `Demo_Lecture_7.slnx` або у Visual Studio: *File → Open → Project/Solution* і вибрати цей файл. У Solution Explorer з'являться дев'ять проєктів і тека **Сценарії** з файлами `.cmd`.

> Файл рішення збережено в новому форматі `.slnx`. Його відкривають свіжі версії Visual Studio; якщо ваша версія повідомляє, що формат невідомий, оновіть Visual Studio або відкрийте потрібний проєкт напряму — *File → Open → Project/Solution* і вибрати `.vcxproj`.

**Крок 2. Перевірити конфігурацію.** На панелі зверху мають стояти **Debug** і **x64**.

**Крок 3. Зібрати.** *Build → Build Solution* (Ctrl+Shift+B). Програми з'являться в `x64\Debug\`.

**Крок 4. Запускати через сценарії.** Більшість демонстрацій треба запускати **кілька разів з різними параметрами й перенаправленням** (`> out.txt`, `2>&1`) — це зручніше робити сценаріями з теки `Сценарії`, а не кнопкою запуску. Відкрийте вбудований термінал: *View → Terminal* (Ctrl+~), перейдіть у теку і запускайте:

```
cd Сценарії
demo01_hook.cmd
```

**Якщо все ж запускаєте з Visual Studio — лише Ctrl+F5.** Правою кнопкою на проєкті → **Set as Startup Project**, потім **Ctrl+F5** (*Start Without Debugging*): вікно консолі лишиться відкритим. Під F5 вікно закриється одразу, а демонстрації з вводом і клавішами (`Demo4_scanf`, `Demo5_fgets`, `Demo8_keys`) поводитимуться інакше.

Аргументи (`crash`, `raw`, `events`…) задаються так: правою кнопкою на проєкті → *Properties* → **Configuration Properties → Debugging → Command Arguments**.

**Не вимикайте прапорець `/utf-8`.** Він заданий у властивостях кожного проєкту (*C/C++ → Command Line → Additional Options*) і потрібен тому, що вихідні файли збережено в UTF-8. Без нього зіпсується кирилиця в `Demo2_printf` і `Demo7_cyr`.

## Як зібрати з командного рядка

**Developer Command Prompt for VS**, з кореня репозиторію:

```
msbuild Demo_Lecture_7.slnx /p:Configuration=Debug /p:Platform=x64
```

Або окремий файл — наприклад, щоб швидко перевірити свою зміну:

```
cl /utf-8 /W4 Demo4_scanf\scanf.c
```

Зібраний так `scanf.exe` з'явиться в поточній теці; сценарії його не знайдуть — вони шукають `x64\Debug\Demo4_scanf.exe`. Для сценаріїв перезбирайте рішення.

## Як запускати без сценаріїв

З теки `x64\Debug`:

```
Demo1_lost.exe crash                 у консолі - три рядки
Demo1_lost.exe crash > out.txt       у файлі - нуль байт
Demo1_lost.exe crash flush > out.txt з fflush - текст на місці

Demo6_order.exe > all.txt 2>&1       спершу рядки stderr, потім stdout

Demo7_cyr.exe raw | cp | wide | api
Demo8_keys.exe line | events
```

## Відомі граблі

**Кодування сценаріїв.** Файли `.cmd` збережено в **UTF-8 з CRLF**, перший рядок після `@echo off` — `chcp 65001 > nul`. Якщо перезберегти їх в іншому кодуванні або з LF-закінченнями, українські рядки розсиплються, а `cmd` почне сприймати їх як команди.

**Кодова сторінка після `Demo7_cyr`.** Сценарій `demo07_codepage.cmd` на час показу перемикає консоль у 866 і повертає 65001. Якщо запускаєте `Demo7_cyr.exe` вручну, пам'ятайте: `SetConsoleOutputCP` змінює налаштування **всієї консолі**, а не лише програми.

**`type` файлу з VT-послідовностями.** Консоль знову виконає ці послідовності, і «сміття» у файлі не буде видно. Відкривайте такий файл у Блокноті — або дивіться, як це робить `demo09_escape.cmd`.

**`Ctrl+Z` зі `scanf`.** У консолі Windows зі `scanf("%d")` він спрацьовує лише з третього разу. Кінець введення показано на `fgets` у `Demo5_fgets` — там працює одразу.

**Вікно звіту про помилку.** `Demo1_lost` навмисно аварійно завершується; `SetErrorMode` у коді прибирає вікно звіту Windows. Якщо все ж з'явилось — просто закрийте його.
